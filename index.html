Instruções para usar o VR

  1. Use as setas do teclado para se mover no ambiente virtual.
  2. Use o cursor vermelho para interagir com os objetos no ambiente.
  3. Para selecionar um objeto, aponte o cursor e pressione a tecla Espaço.
  4. Mantenha-se atento ao tempo e à pontuação exibidos no topo da tela.

Olá! Bem-vindo! :)

Sobre o projeto "Mundo em 3D": é uma iniciativa inovadora do curso de Engenharia de Software da Universidade Estadual de Ponta Grossa (UEPG), situada no Paraná, voltada para a integração de tecnologias emergentes no ambiente educacional. Seu objetivo principal é explorar o potencial da Realidade Virtual (VR) como ferramenta pedagógica para enriquecer o processo de ensino-aprendizagem em escolas da região.

A Realidade Virtual cria ambientes completamente digitais, permitindo que os estudantes sejam imersos em mundos virtuais onde podem interagir com objetos e cenários tridimensionais. Por meio deste projeto, a UEPG busca transformar a maneira como os conteúdos escolares são apresentados, proporcionando uma experiência educacional mais envolvente e interativa.

As tecnologias usadas são HTML, CSS, JS e o framework A-Frame com VR para Web. O projeto foi desenvolvido pelos acadêmicos Michel e Caroline, no 2º ano do curso de Engenharia de Software.
